# Hub24Marcin 💜

**Connect. Explore. Grow.**

Hub24Marcin is an independent, mobile-first career-support resource with practical CV guidance, selected Accenture opportunity links, employee referral guidance and Workday application guidance.

## Website structure

- Career Hub landing page
- Employee referral process and eligibility reminder
- Consolidated selected-country directory linking to official Accenture career searches
- CV readiness checklist
- Workday application guidance
- Candidate FAQ
- About Hub24Marcin
- LinkedIn, Linktree and Ko-fi destinations

## Technology

The site deliberately uses plain **HTML, CSS and JavaScript** with no framework or external runtime dependencies. This keeps GitHub Pages hosting fast, inexpensive and easy to maintain.

- `index.html` — page content and semantic structure
- `assets/css/styles.css` — responsive design system, mobile layout and dark theme
- `assets/js/app.js` — country directory, navigation and theme behaviour

### Updating countries

Edit the `countries` array near the top of `assets/js/app.js`. Each entry contains the flag, display name and official Accenture careers URL.

## Publishing with GitHub Pages

After the reviewed build is merged to `main`, enable GitHub Pages for the repository and publish from the main branch/root directory. A custom domain can be added later without changing the site architecture.

## Important disclaimer

Hub24Marcin is an independent career-support resource created by an Accenture employee. It is **not an official Accenture recruitment website**. Employee referrals do not guarantee an interview, progression or employment. Recruitment and hiring decisions remain with Accenture's recruiting and hiring teams.

The public website intentionally does not display a personal email address.
